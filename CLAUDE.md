## Critical: this is bleeding-edge Next.js

This project runs **Next.js 16.3.0**, which post-dates your training data and has breaking changes versus the Next.js you know (APIs, conventions, file structure may all differ). Before writing any Next.js code, read the relevant guide under `node_modules/next/dist/docs/` (e.g. `01-app/` for App Router). Heed deprecation notices you find there.

`AGENTS.md` in the repo root carries this same instruction and is regenerated by `next dev` on every run (see `node_modules/next/dist/server/lib/generate-agent-files.js`) — don't strip it from diffs; committing it keeps the tree clean.

## Project state

This is a freshly bootstrapped `create-next-app` project (single "Initial commit" so far) with no custom features implemented yet — `src/app/page.tsx` is still the default starter page. There is no established architecture to follow yet; the App Router structure under `src/app/` is the only convention in place.

## Commands

- `npm run dev` — start the dev server (http://localhost:3000)
- `npm run build` — production build
- `npm run start` — run a production build
- `npm run lint` — ESLint (flat config via `eslint.config.mjs`, extends `eslint-config-next` core-web-vitals + typescript rules)

No test runner is configured in this project yet.

## Stack notes

- **App Router** under `src/app/`, TypeScript, React 19.
- **React Compiler** is enabled (`reactCompiler: true` in `next.config.ts`) — avoid manual `useMemo`/`useCallback` micro-optimizations; let the compiler handle memoization.
- **Tailwind CSS v4** via `@tailwindcss/postcss` (no `tailwind.config.*` file — v4 is configured through CSS in `src/app/globals.css`).
- Path alias `@/*` maps to `src/*` (`tsconfig.json`).
